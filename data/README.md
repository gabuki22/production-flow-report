## ⚠️ 실험 데이터는 설계이지 실행 기록이 아니다

`experiments` · `experiment_assignments` 는 **2026-09-01에 만들었다.**
7주차에 *설계만* 해 둔 것(그룹당 5,298건 · 41일 · 스위치백)을 데이터로 옮겨
**앱의 판정 절차가 실제로 도는지** 확인하려고 만든 것이다.

**우리는 이 실험을 돌린 적이 없다.** 성과를 실적으로 인용할 수 없고,
리포트 5장·7장이 이 사실을 문장으로 남긴다.

세 건인 이유 — 한 건만 만들면 **판정 분기가 한 갈래만 돌아 본다.**
못 믿을 조건에 실제로 걸리는 건을 일부러 섞어야 `trust_check()` 가 작동하는지 눈으로 볼 수 있다.

| | 상태 | 왜 |
|---|---|---|
| EXP-001 자재 입고 로트 검사 강화 | 계산까지 간다 | 배정 50.9:49.1 · 표본 10,600 · 55일 |
| EXP-002 색상 묶음 순서 조정 | **무효(배정)** | 61.9:38.1 로 깨뜨려 뒀다 |
| EXP-003 지시서 조기 발행 | **무효(표본·기간)** | 64건 · 11일 |

**EXP-001 이 "효과 없음"으로 나오는 것은 발견이 아니다.** 배정은 나중에 만들었고
불량 데이터는 그 전에 만들어져서, 배정이 결과에 영향을 줄 수 있는 경로가 애초에 없다.
효과를 심어 넣지 않은 이유 — 심으면 **하지도 않은 실험이 "성공"으로 리포트에 실린다.**
계산기가 제대로 도는지는 대신 `tests/test_metrics.py` 가 **답을 아는 표본**으로 확인한다.

다시 만들려면:

```bash
py -X utf8 _generator/gen_experiments.py
```

시드 `20260901` 고정 — 다시 돌리면 같은 데이터가 나온다.

> `납기일` 은 **예정** 컬럼이라 관측 목록에 없다. 기간 밖이 정상이기 때문이다
> — 2026-08-29 기준 10,293건(10.7%)이 아직 오지 않은 납기다.

## 다시 만들려면

CSV 69.3MB 가 parquet 8.5MB 가 된다 (12%). 원본은 읽기만 한다.

```
../mydomain/data/ 의 orders·order_events·defect_events·product_cost_bom·worklog_검사 를
읽어서 data/ 에 parquet 으로 저장해줘. 원본 CSV 는 건드리지 마.
```

## 데이터를 바꾸려면

1. 파일을 이 폴더에 넣는다 — **parquet · csv · 엑셀** 다 된다
2. `core/config.py` 의 `TABLES` 에 **파일명(확장자 제외)** 을 적는다
3. `VALIDATION` 의 `기준행`·`필수컬럼`·`관측컬럼` 도 함께 고친다 — 검증이 그 표를 읽는다

파일이 하나뿐이어도 된다. 조인이 없으면 조인 함정도 없다.

엑셀에서 저장한 CSV 는 인코딩이 두 갈래(UTF-8 / cp949)인데 `core/load.py` 가 둘 다 시도한다.
한글이 깨져 보이면 코드가 아니라 **저장 형식**을 확인한다.
