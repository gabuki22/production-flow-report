# 03. 지표 정의서 — 납기 준수율

> ⚠️ **현재값은 합성 데이터 기준이다.** 임계값(경고·위험)은 **현장 기준으로 정한 실제 값**이다.
> 데이터 → [[01_데이터]] · 실측 → [[02_퍼널실측]]

## 계산식

```
납기 준수율 = 납기일 이내에 출하된 수주 수
             ─────────────────────────────
             납기일이 도래한 수주 수
```

| | |
|---|---|
| **그레인** | ~~수주 1건 (수주ID)~~ → **제품도번 1개** (2026-09-12 개정 — 실 ERP 에 수주 식별자가 없다, `notes/11`). ~~도번 안의 발주 건은 그대로 고유값으로 센다~~ → **09-12 오후 정정(기쁨)**: 퍼널은 *멈춘 발주가 있는 도번 수*(`funnel_parts`), 축별 준수율은 *도번 준수율의 평균*(`metric_by_parts`), 크기는 격차 × 그쪽 발주 수. 발주 단위는 재료로 남긴다. 도번 평균 vs 발주 가중 차이 0.07%p 이내 |
| 분자 | `출하` 이벤트일 ≤ `orders.납기일` 인 수주 (최초 출하만) |
| 분모 | `orders.납기일` ≤ 기준일 인 수주 (**납기일 결측 7% 제외**) |
| 데이터 | `data/orders.csv` · `data/order_events.csv` |

## ★ 분모를 이렇게 정한 이유

같은 이름의 지표가 분모만 바꿔 세 값이 된다.

| 분모 | 값 | 판정 |
|---|---:|---|
| ① 출하한 건만 | 95.7% | ✕ **미납이 분모에서 빠진다** |
| ② **납기 도래 전체** | **91.1%** | ★ **채택** |
| ③ 전체 수주 | 81.9% | ✕ 납기 안 온 건까지 실패로 센다 |

**납기일이 지난 수주는 전부 준수 여부를 판정할 기회가 있었다.**
출하 못 한 것은 "판정 대상 아님"이 아니라 **"납기 못 지킴"**이다.

> ⚠️ **①을 쓰면 굿하트의 법칙에 걸린다** — 어려운 건을 출하 안 하고 미루면
> 분모에서 빠져 **지표가 올라간다.** 지표를 올리려고 미납을 늘리는 유인이 생긴다.

## 유효구간

**2025-09 ~ 2026-08 (12개월).** 규모가 커져 전 기간이 최소 표본 100건을 넘는다.
(1차 규모에서는 2개월이 표본 미달로 빠졌다)

## 현재값과 임계값

| | 값 | 근거 |
|---|---:|---|
| **현재값** | **91.1%** | 71,918 / 78,987 (합성) |
| **경고** | **90% 미만** | ★ 현장 기준 — *"90% 미만이면 경고해야 한다"* |
| **위험** | **80% 미만** | ★ 현장 기준 — *"80% 이상은 되어야 한다"* |
| **최소 표본** | **100건** | 월 분모 평균 6,582건. 100건이면 월 단위 판정 가능, 더 쪼개면 못 쓴다 |

### 임계값 근거 한 줄

> **납기는 고객과의 약속이라 90%는 지켜져야 하는 선이고, 80%를 밑돌면 거래 자체가 위태롭다.**
> 통계적 변동폭(±1.96%p)이 아니라 **사업이 감내할 수 있는 선**에서 그었다.
> 데이터는 *"검출 가능한가"*까지 답하지만 *"감내 가능한가"*는 답하지 못한다(3회차 고정 ④).

## 보조 지표 (같은 코호트 기준)

| 지표 | 현재값 | 방향 |
|---|---:|---|
| 공정 통과율 (공정작업 → 출하) | 98.4% | 높을수록 좋음 |
| **미납률** | **6.2%** | ⚠️ **낮을수록 좋음 — 부등호가 뒤집힌다** |
| 지연 출하 비율 | 4.3% (중앙값 13일) | ⚠️ 낮을수록 좋음 |
| **불량률** → [[07_불량률가드레일]] | **3.56%** (경고 4 · 위험 5) | ⚠️ 낮을수록 좋음 |

⚠️ 방향이 반대인 지표는 **경고·위험선의 부등호도 뒤집어야 한다**(3회차 확정).
미납률은 *"N% 미만이면 정상"*이 아니라 *"N% 초과면 경고"*로 쓴다.

## 이 지표로 답할 수 없는 것

- **왜 늦었는가** — `변경사유`가 5종뿐이고 98.7%가 결측이다
- ~~**얼마나 손해인가**~~ → ✅ **해소.** 원가가 붙었다 → [[06_원가연결]]
- **어느 공정에서 밀렸는가** — `공정작업`이 한 덩어리다
- **고객이 실제로 불만인가** — 클레임·CS 데이터가 없다
- **납기가 애초에 무리였는가** — 납기 협의 이력이 없다. *지킬 수 있는 납기였는지*를 모른다
- **납기일 결측 7%** — 이 건들은 분모에서 아예 빠진다. 결측이 무작위가 아니면 편향된다
