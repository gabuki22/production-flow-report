# 08. 실험 설계 — H1 불량 스파이크 사전 차단

> 가설 → [[05_가설]] H1 · ⚠️ **합성 데이터 기준**

## 가설

```
자재 입고 로트 검사를 강화하면
불량 스파이크 발생률이 4.0% → 3.0% 로 내려간다 (상대 25%)
단, 납기 준수율은 2%p 이상 나빠지지 않는다
```

## 1. 표본 크기

| | |
|---|---|
| 산식 | `n = (Z_α/2 + Z_β)² × (p₁(1−p₁) + p₂(1−p₂)) / (p₁−p₂)²` |
| 검정력 | 0.80 (Z_β = 0.842) · α 0.05 양측 (Z_α/2 = 1.960) |
| 기준값 | **4.0%** (실제 조회 — 3,736 / 92,518) |
| 목표 | 3.0% |
| **그룹당** | **5,298건** · 총 10,596건 |

## 2. 대안 검토 — 못 쓰는 안을 지운다

일평균 공정작업 **260건**.

| 목표 | 상대 개선 | 그룹당 | 기간 | 판정 |
|---|---:|---:|---:|---|
| 3.0% | 25.0% | 5,298 | **41일** | **○ 채택** |
| 2.8% | 30.0% | 3,577 | 28일 | △ 30% 개선은 낙관적 |
| 2.0% | 50.0% | 1,139 | 9일 | ✕ 검사 하나로 절반은 비현실적 |
| 3.5% | 12.5% | 21,847 | 168일 | ✕ 분기를 넘긴다 |

> ★ **4회차와 달라진 점**: 그때는 목표 10%면 155일이 걸려 15%로 올려야 했다.
> 지금은 **일평균 대상자가 37명 → 260건**이라 **표본이 더 이상 병목이 아니다.**
> *"최소표본 1000은 성립하지 않는다"*던 4회차 결론이 규모 현실화로 뒤집혔다.

## 3. MDE — 기간을 고정하면 무엇을 검출할 수 있나

| 기간 | 검출 가능 최소 효과 (상대) |
|---|---:|
| 4주 | 29.8% |
| 8주 | 21.5% |
| **12주** | **17.8%** |

⚠️ **MDE는 검정력 0.80 기준**이지 유의 경계가 아니다.
4주만 돌리면 상대 25% 개선이 있어도 **놓칠 확률이 20%를 넘는다.**

## 4. 배정

**처치가 걸리는 범위를 먼저 판정한다** (4회차 정정).

| 처치 범위 | 배정 단위 | 설계 |
|---|---|---|
| 자재 로트 하나에만 | 로트 | 개별 무작위 ✅ |
| **입고 검사 절차 전체** | **주차 블록** | **스위치백** ⚠️ |

**이 처치는 "검사 절차"라 로트별로 나눌 수 없다.** 검사원이 같은 날 두 기준을 오갈 수 없다.

| | |
|---|---|
| **배정 단위** | **주차** (A주 강화 / B주 현행 교차) |
| 배정 시점 | 자재 입고 |
| 비율 | 50:50 (주 단위 무작위) |
| 필요 주차 | 그룹당 5,298건 ÷ 주 1,300건 ≈ **각 4주 · 총 8주** |

### ⚠️ 스위치백의 위험 — 이월 효과

**지난주에 걸러낸 불량 자재가 이번 주 결과에 영향을 준다.**
자재는 입고 후 며칠~몇 주 뒤에 투입되므로 **주 경계가 깨끗하지 않다.**

> 대응: **각 주의 첫 2일을 집계에서 제외**(워시아웃)하고, 자재 입고일 기준으로 귀속한다.
> 그래도 완전히는 못 막는다 — **한계로 적는다.**

## 5. 종료 조건 ★ 시작 전에 정한다

```
정상 종료:  그룹당 누적 5,298건 도달   또는   착수일 + 70일 (상한)
            ↑ 주 조건                        ↑ 안 차면 "표본 미달"로 판정
```

**날짜가 아니라 누적 건수가 주 조건이다**(4회차 확정). 발주량이 흔들려 날짜가 표본을 보장하지 못한다.

| 중간에 봐도 되는가 | |
|---|---|
| 배정이 50:50인지 | **본다** |
| 시스템 정상 작동 | **본다** |
| **가드레일(납기 준수율)이 무너지는지** | **본다 — 안전 문제다** |
| **주지표가 유의한지** | **보지 않는다** |

> 매일 보면서 좋을 때 멈추면 헛것을 잡을 확률이 **5% → 28.5%**로 뛴다(4회차 실측 시뮬).

## 6. 결과 확인 절차 — 순서를 지킨다

```
1. 배정 균형     주차 배분이 4:4인가. 물량·차종 구성이 같은가
2. 주지표        스파이크 발생률 · 신뢰구간 · p값
3. 가드레일      납기 준수율 (함께 본다)
4. 기간별 분해   2주 단위. 효과가 유지되는가
```

**주지표를 먼저 보면** *"배정이 좀 깨졌지만 이만큼 좋은데"*가 된다.
**의지에 맡기면 언젠가 무너지고, 절차로 만들면 안 무너진다.**

## 7. 반증 조건

| # | 조건 | 판정 |
|---|---|---|
| ① | 개선이 **상대 25% 미만** | 효과 미달 → 실패 |
| ② | **p ≥ 0.05** | 유의하지 않음 → 실패 |
| ③ | **납기 준수율 2%p 이상 하락** | ★ **주지표가 좋아져도 실패** |
| ④ | 두 집단의 **물량·차종 구성이 다름** | 비교 무효 *(SRM 대체 — 3회차 확정)* |
| ⑤ | 후반 2구간 효과가 목표의 절반 미만 | 신규성 → 전면 적용 보류 |

## 8. ⚠️ 되돌릴 수 없다 — 원복 절차를 설계에 넣는다

수업 실험은 화면을 바꾸는 것이라 실패해도 원복하면 끝이다.
**우리는 실제 생산을 건드린다.** 검사를 강화해 자재 투입이 늦어지면 **진짜 납기 사고**다.

| 상황 | 조치 |
|---|---|
| 납기 준수율 2%p 하락 | **즉시 전 라인 현행 복귀** (당일) |
| 자재 대기 재고 급증 | 검사 기준 완화 후 재검토 |
| 원복 소요 | **1일** — 절차만 되돌리면 되므로 |

## 9. 한계 — 이 실험으로 답할 수 없는 것

- **상대 25% 미만은 놓칠 확률이 20%를 넘는다.** *"유의하지 않음"* ≠ *"효과 없음"*
- **어느 원인이 줄었는지 모른다** — 원인구분 4종이 사후 라벨이다
- **검사 비용을 못 잰다** — 공수 데이터가 없어 **비용 가드레일을 못 건다.**
  이것이 이 설계의 가장 큰 구멍이다 — *"불량은 줄었는데 더 비쌌다"*를 못 잡는다
- **스위치백 이월 효과를 완전히 못 막는다** — 자재 입고와 투입 사이에 시차가 있다
- **전부 합성이다.** 스파이크를 우리가 심었고, 그 빈도(4%)도 역산값이다
