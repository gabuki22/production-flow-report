# 05. 가설 3개

> ⚠️ **합성 데이터 기준.** 재료는 오늘 실제로 조회한 것에서만 골랐다.
> 데이터 → [[01_데이터]] · 실측 → [[02_퍼널실측]] [[06_원가연결]] [[07_불량률가드레일]]

## ★ 우리 도메인의 가드레일 방향

수업의 획득 퍼널은 *"많이 데려오려다 질을 잃는 것"*을 막았다.
우리는 다르다 — **"납기를 지키려다 다른 것을 잃는 것"**을 막아야 한다.

3회차에서 확정한 대로 **주지표 넷이 서로의 가드레일**이 된다.

| 주지표를 올리는 방법 | 희생되는 것 | 가드레일 |
|---|---|---|
| 불량률 ↓ — 검사 강화 | **납기** (검사에 시간이 든다) | 납기 준수율 |
| 지연 ↓ — 급하게 밀어냄 | **품질** | 불량률 |
| 적자 ↓ — 단가 인상 | **물량** | 수주 건수 |

---

## H1 — 불량 스파이크 사전 차단

### 조작적 정의

```
자재 입고 로트 검사를 강화하면
불량 스파이크 발생률이 4.0% → 3.0% 로 내려간다 (상대 25%)
단, 납기 준수율은 2%p 이상 나빠지지 않는다
```

| | |
|---|---|
| **주지표** | 스파이크 발생률 — **현재 4.0%** (3,736 / 92,518) |
| **가드레일** | 납기 준수율 — 현재 91.1% · **89.1% 미만이면 중단** |
| 가드레일 근거 | 경고선이 90%다. 그 아래로 2%p 더 내려가면 위험선(80%)까지 절반을 잃는다 |

### 왜 이 가설인가

**4%의 배치가 월 불량률 지표의 30%를 만든다.** 스파이크를 빼면 월별이 2.4~2.6%로 평평하다.
금액으로는 **불량 손실 90.2억 중 33%가 스파이크분**이다 — 이익의 약 7%.

원인구분별 스파이크율은 금형 4.16% · 설비 4.14% · 자재 4.01% · 페인트 3.73%로
**격차가 0.43%p뿐이고 χ²=6.50 · p=0.0896 (본페로니 α=0.0125)로 우연 범위**다.
라벨을 200회 무작위로 섞어도 이만한 격차가 **14%의 확률로 나온다**(86분위) → [[09_판정]]

> ✂️ **정정**: 초안에 *"자재 4.4%로 최고"*라고 적었으나 **1차 규모의 값을 옮긴 오류**였다.
> 재생성 후 자재는 **3위**이고, 애초에 **원인별 차이 자체가 없다.**
> → **어느 원인부터 볼지는 데이터가 정해주지 않는다.** 현장 판단으로 고른다.

### 반증 조건

| # | 조건 | 판정 |
|---|---|---|
| ① | 스파이크 발생률 개선이 **상대 25% 미만** | 효과 미달 → 실패 |
| ② | **p ≥ 0.05** | 유의하지 않음 → 실패 |
| ③ | **납기 준수율 2%p 이상 하락** | ★ **주지표가 좋아져도 실패** |
| ④ | 배정 두 집단의 물량·차종 구성이 다름 | 비교 무효 |

### 답할 수 없는 것

- **어느 원인이 줄었는지** — 원인구분이 4종뿐이고 스파이크 귀속이 사후 라벨이다
- **검사 공수가 얼마나 늘었는지** — 공수 데이터가 없다. **비용 가드레일을 못 건다**
- 자재 로트 이력이 없어 **같은 로트가 여러 배치에 걸치는지** 모른다

## H2 — 지연 출하 감소

### 조작적 정의

```
납기 임박 건에 공정 우선순위를 부여하면
지연 출하율이 4.3% → 3.2% 로 내려간다 (상대 25.6%)
단, 불량률은 1%p 이상 나빠지지 않는다
```

| | |
|---|---|
| **주지표** | 지연 출하율 — **현재 4.3%** (3,314 / 76,415) |
| **가드레일** | 불량률 — 현재 3.56% · **4.56% 초과면 중단** |
| 가드레일 근거 | 경고선이 4%다. 1%p 오르면 경고를 넘어 위험선(5%)에 닿는다 |

### 왜 이 가설인가

**우리 병목은 "새는" 게 아니라 "밀리는" 것**이다([[02_퍼널실측]] C절).
퍼널은 98.4~99.5%로 평평한데 **납기 축에서만 문제가 보인다** — 지연 중앙값 13일·최대 24일.

⚠️ **주지표를 납기 준수율(91.1%)로 잡지 않았다.** 개선 여지가 8.9%p뿐이라 천장에 가깝다.
같은 현상을 **지연 출하율(4.3%)**로 보면 여지가 훨씬 크고 표본도 적게 든다
(Day2 고정 ⑦ — *물어야 할 것은 천장까지 남은 거리*).

### 반증 조건

| # | 조건 | 판정 |
|---|---|---|
| ① | 지연율 개선이 **상대 25% 미만** | 효과 미달 → 실패 |
| ② | **p ≥ 0.05** | 유의하지 않음 → 실패 |
| ③ | **불량률 1%p 이상 상승** | ★ **주지표가 좋아져도 실패** |
| ④ | 우선순위를 준 건 밖에서 **지연이 늘어남** | 풍선효과 → 실패 |

> ④가 이 가설의 진짜 위험이다. **우선순위는 총량을 늘리지 않고 순서만 바꾼다.**
> 앞에 세운 만큼 뒤가 밀리면 전체는 그대로다.

### 답할 수 없는 것

- **어느 공정에서 밀렸는지** — `공정작업`이 한 덩어리다
- **밀어낸 만큼 다른 건이 밀렸는지** — 실험군 밖을 같이 봐야 하는데 배정 설계에 달렸다
- **납기가 애초에 무리였는지** — 납기 협의 이력이 없다

## H3 — 적자 수주 관리

### 조작적 정의

```
적자 도번의 단가를 재협상하면
적자 수주 비율이 17.5% → 15.0% 로 내려간다 (상대 14.3%)
단, 해당 고객사 수주 건수가 10% 이상 줄지 않는다
```

| | |
|---|---|
| **주지표** | 적자 수주 비율 — **현재 17.5%** (16,800 / 96,000) |
| **가드레일** | 대상 고객사 수주 건수 — **10% 이상 감소 시 중단** |
| ⛔ **착수 조건** | **실 원가 확보 전 보류** → [[09_판정]] 발견 ③ |
| 가드레일 근거 | 단가를 올리면 물량이 빠진다. **적자를 없애려다 매출을 잃으면 손해**다 |

### 왜 이 가설인가

**1,200 도번 중 211개(17.6%)가 적자**이고, 그 도번이 수주의 17.5%를 차지한다.
이익률 하한이 −4.2%다.

⚠️ **굿하트의 법칙이 가장 직접적으로 걸리는 가설이다.**
*"적자 수주 비율"*만 목표로 삼으면 **적자 건을 안 받는 것**이 최적해가 된다.
그러면 지표는 좋아지고 **총이익은 줄어든다.**
→ 그래서 가드레일을 **비율이 아니라 건수**로 걸었다.

### 반증 조건

| # | 조건 | 판정 |
|---|---|---|
| ① | 적자 비율 개선이 **상대 14% 미만** | 효과 미달 → 실패 |
| ② | **p ≥ 0.05** | 유의하지 않음 → 실패 |
| ③ | **대상 고객사 수주 건수 10% 이상 감소** | ★ **주지표가 좋아져도 실패** |
| ④ | **총이익 절대액이 줄어듦** | ★ 비율이 좋아져도 실패 |

### 답할 수 없는 것

- **협상이 실제로 되는지** — 데이터로 답할 수 없는 사업 문제다
- ★ **원가가 맞는지** — 이익률 가정을 8%→12%로 올리면 **적자가 17.6% → 2.2%로 사라진다.**
  **적자 비율은 데이터가 아니라 가정의 출력이다** → [[09_판정]]
- **고객사별 단가 차이** — 실제로는 도번×고객사 다중행인데 우리는 도번당 1행이다

---

## ⚠️ 세 가설의 공통 한계 — 관찰 재료가 스파이크에 편중돼 있다

분해를 해봤지만 **격차가 없다.**

| 축 | 범위 | 판정 |
|---|---|---|
| 고객사 | 90.6 ~ 91.5% | 격차 0.9%p |
| 차종 | 90.8 ~ 91.6% | χ²=4.39 · p=0.494 **우연** |
| 수량 구간 | 91.0 ~ 91.2% | 격차 0.2%p |
| 설비호기 | 3.53 ~ 3.60% | 격차 0.07%p |

**당연하다 — 생성기에 축별 차이를 심지 않았다.** 유일하게 심은 패턴이 **불량 스파이크의 월별 군집**이라,
관찰할 수 있는 것도 거기 몰린다.

> **합성 데이터의 가설은 "무엇을 심었나"를 되찾는 일에 가깝다.**
> 실데이터에서는 우리가 모르는 패턴이 나온다 — 그것이 진짜 분석이다.
> **방법은 여기서 검증되고, 판정은 실데이터로만 한다.**
