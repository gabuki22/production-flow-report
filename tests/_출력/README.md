# tests/_출력/ — 검사가 만든 것

> 검사를 돌리면 나오는 결과물을 여기 모은다. **소스가 아니라 산출물이다.**
> 지워도 앱은 돈다 — 다시 돌리면 다시 나온다.

2026-09-01 신설. 그 전에는 `_작업보조/` 에 백업과 섞여 있어서
**어느 것이 롤백용 백업이고 어느 것이 검사 부산물인지 구분되지 않았다.**

| 여기 | 저기(`_작업보조/`) |
|---|---|
| 검사가 만든 것 — 지워도 된다 | 롤백용 원본 — **지우면 되돌릴 수 없다** |

## 들어 있는 것

### `리포트_확인용.pdf`

리포트 8장이 실제로 PDF로 조립되는지 확인한 결과물(155KB).
한글 폰트·차트 3종·`**강조**` 처리가 눈으로 확인되는 자리다.

다시 만들려면 앱의 **리포트 → PDF 만들기** 를 누르거나, `tests/test_app.py` 를 돌린다.

### `실행기록/*.json` — 5건

**검사가 만든 게이트 통과 기록이다. 사람의 판단이 아니다.**

`tests/test_app.py` 가 게이트 1·2를 통과시키는데, 그때 `gates.save()` 가
**진짜 `runs/` 에 썼다.** runs/ 는 일부러 git 추적 중이라 5건이 커밋까지 따라갔다.

> 아카이브는 *"누가 언제 무엇을 보고 통과시켰는가"* 가 남는 자리다.
> 검사가 만든 기록이 섞이면 **판단 증거와 잡음을 구분할 수 없다.**

- **원인은 막았다** — 검사가 `config.RUNS_DIR` 을 임시 폴더로 갈아끼운다
  (`tests/test_app.py` 상단). 돌려도 `runs/` 가 안 늘어나는 것을 확인했다.
- 이미 쌓인 5건은 **지우지 않고** 여기로 옮겼다. 근거 문구가 전부 같아서
  검사가 만든 것임을 그 자체로 알 수 있다.
- `runs/20260901-203254.json` 하나만 남겼다 — 8주차 Day1에 **사람이** 통과시킨 기록이다.

**롤백**: `move tests\_출력\실행기록\*.json runs\`
